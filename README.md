# pissfactory

revel in the glory

## setup

- import <https://minecraft.catgirl-v.org/packs/pissfactory/pissfactory.zip> into prismlauncher
  (other launchers arent supported and if you use anything else you should feel
  bad anyway)
- point the instance at your java17+ runtime (21+ recommended)
- ensure 6-8GiB memory is allocated to the game
- optionally check recommended JVM flags: <https://exa.y2k.diy/garden/jvm-args/>
- launch
