# pissfactory

revel in the glory

## setup

- import https://catgirl-v.github.io/pissfactory/pissfactory.zip into prismlauncher
  (other launchers arent supported and if you use anything else you should feel
  bad anyway)
- point the instance at your java17+ runtime (21+ recommended)
- ensure 6-8GiB memory is allocated to the game
- launch
